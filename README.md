# hxyfront-62013 木结构隐患处置台

雨后巡查木结构隐患的登记、复核与处置闭环工具。巡查人员把纸单上的渗水、裂缝、松动等情况回工棚后直接登记进台账，同一构件不拆成多条处置单。

## 业务规则

- 登记字段：建筑、构件编号、部位、类型（渗水/裂缝/松动/糟朽/变形）、等级（一般/严重）、发现人和发现时刻。
- 同一构件（同建筑 + 同构件编号）存在未关闭处置单时，新检查只作为一条检查记录追加到原单，并沿用原处置单号；登记时页面会提示命中的原单。
- 严重隐患必须由他人复核：复核人不能与发现人为同一人；复核前清单徽标、尺寸表和病害图均显示「待复核」遮罩。复核通过后进入待处置，退回则补充检查并留痕。
- 复核通过后填写处置人和处置意见才能关闭；每次检查的时间与结论在处置单时间线中永久保留。
- 存在任何未关闭处置单时，「导出施工清单」按钮禁用；全部关闭后方可导出 CSV。

## 文件划分（规则 / 存储 / 页面各一个业务文件）

- `src/rules.ts`：处置单数据模型与全部业务规则（开单、追加、复核、关闭、导出），均为纯函数。
- `src/storage.ts`：localStorage 台账持久化与示例数据（待复核 / 待处置含复查追加 / 已关闭三种形态）。
- `src/App.tsx`：巡查登记、隐患清单筛选、处置单详情（检查时间线、尺寸表、病害图、复核与关闭）。
